`source.md` format, commands, conventions and gotchas. It applies in full to Claude Code; this file

## The short version

- **The history is not ours.** `source.md` is the README of
  [AlighieriDemiurgs/MuHistory](https://github.com/AlighieriDemiurgs/MuHistory), vendored with
  attribution. Do not rewrite or "correct" it — corrections go upstream. This repo is the
  presentation layer only.
- **`source.md` is the single source of truth.** `src/content/seasons/*.md` and
  `src/data/references.json` are generated by `scripts/split-source.mjs` on every build and are
  git-ignored. Never edit the generated files — they are overwritten on every build.
- Static Astro 5 site, Tailwind 4 (CSS-configured via `@theme`, no JS config file), Biome for
  lint/format. No UI framework.
- Before finishing: `npm run check` and `npm run lint` must both pass, and `npm run build` must
  complete.
